## Objective

Native-Mac polish nobody does well (gap #4): exact window sizes relative to the source and a menu-bar item for quick control, optionally without a Dock icon.

## Relevant files / modules

- `Apps/macOS/Sources/HDMICaptainApp.swift` — Window menu commands + MenuBarExtra scene
- `Apps/macOS/Sources/WindowConfigurator.swift` — apply size presets
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Window → Size: 50 %, 100 % (⌘0), 150 %, 200 % of source pixels, and 'Actual Pixels (1:1)' using backingScaleFactor; clamp to screen visibleFrame.
2. MenuBarExtra: current device, device list, mute, volume slider, float on top, show/hide window, quit.
3. Pref 'Show in menu bar only' toggles NSApp.setActivationPolicy(.accessory/.regular).
4. Persist the last chosen size preset per device.

## Acceptance criteria

- [ ] ⌘0 makes the content exactly source-size in points×scale (verified with a 1280×720 source on Retina = 640×360 pt at 1:1 pixels)
- [ ] Menu-bar extra controls work while the window is hidden; capture keeps running
- [ ] Menu-bar-only mode survives relaunch
