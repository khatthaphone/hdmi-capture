## Objective

Low-latency GPU preview path (spec §5.4) that later becomes the compositor's backend. Can be built and tested with synthetic pixel buffers before capture exists.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/MetalRenderer.swift` — new
- `Packages/CaptureCore/Sources/CaptureCore/Shaders.metal` — new
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. `CVMetalTextureCache` from bi-planar `420v` buffers (Y + CbCr textures); BGRA passthrough path too.
2. Fragment shader: BT.709 (HD) / BT.601 (SD) matrices; limited vs full range; auto picks from buffer attachments.
3. Scale modes fit/fill/stretch/integer; samplers linear/nearest.
4. Implement as `FrameSink`; keep only latest frame; draw on `MTKView` with `isPaused`+`enableSetNeedsDisplay` driven by new frames.
5. Pause drawing when window occluded (`NSWindow.occlusionState`) — but never touch the capture session.
6. Test harness: generate synthetic SMPTE color bars `CVPixelBuffer` and render to offscreen texture; assert pixel values.

## Acceptance criteria

- [ ] Offscreen render test verifies color bars within ±2 code values for limited & full range
- [ ] Integer scale renders pixel-exact with nearest filter (test)
- [ ] Render of a 1080p frame < 2 ms GPU time on Apple Silicon (Metal capture or signpost)
