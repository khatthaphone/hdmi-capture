**Status:** done

## Objective

Observable catalog of external video devices and audio inputs with hot-plug updates and automatic selection/pairing (spec §5.1).

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/DeviceCatalog.swift` — new
- `docs/research/devices/` — real device data from 002, if available
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. Wrap discovery in a protocol (`DeviceProviding`) so tests can inject fake devices.
2. Publish `videoDevices`, `audioDevices`, `selectedVideo`, `selectedAudio` via `@Observable`.
3. Listen to `wasConnected`/`wasDisconnected` notifications; update lists on main actor.
4. Selection policy: remembered `uniqueID` → most-recently connected external video device.
5. Audio pairing: match `modelID`, then name prefix, then transport type USB; allow manual override.
6. Unit tests with fake devices covering connect, disconnect, remembered-device reconnect, pairing.

## Acceptance criteria

- [ ] Tests pass for: auto-select on connect, deselect on disconnect, reselect remembered device on reconnect, audio pairing order
- [ ] Built-in FaceTime camera is excluded from auto-selection (external only)
- [ ] No AVFoundation calls on main thread that block > 16 ms
