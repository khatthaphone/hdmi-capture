# 055 — iPad touch, pointer & menu-bar UI

**Status:** done
**Phase:** Phase 3: iPadOS
**Depends on:** 053
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Adapt the shell to iPad: tap to show the control bar, touch-sized targets, settings as a sheet, keyboard shortcuts, and the iPadOS 26 menu bar via SwiftUI `.commands`. Clean mode stays the default look: picture only.

## Relevant files / modules

- `Apps/macOS/Sources/ControlBar.swift` — move it to Shared with `#if` for hover vs tap reveal; its `ViewThatFits` layouts already handle narrow windows
- `Apps/macOS/Sources/HDMICaptainApp.swift` — `.commands`; the shared menu views (`PictureLookItems`, `GuideItems`, `SaveRecentItems`) should carry over
- `Apps/macOS/Sources/SettingsView.swift` — present as a sheet/NavigationStack on iPad; drop the Mac-only tabs (menu-bar extra, float on top, all Spaces)
- `Apps/macOS/Sources/Symbols.swift` — shared icon table

## Steps

1. Reveal: a tap toggles the bar, and it auto-hides after 3 s with no interaction. With a trackpad or mouse, keep the macOS bottom-zone hover behaviour (`onContinuousHover`).
2. Make hit targets ≥ 44 pt on touch, and keep the compact layout under ~600 pt (Stage Manager / Split View).
3. Settings sheet: input, format, picture look, audio, guides, Pro. Use the same `ViewerPrefs`.
4. Menu bar and keyboard: reuse the command groups. Commands that can't run on iPad are hidden; commands that can't run right now are disabled, as Apple asks.
5. Status bar and home indicator: hide them while the bar is hidden (`.persistentSystemOverlays(.hidden)`, `.statusBarHidden`).
6. Check that UI overlays still never reach outputs. This is the same rule as macOS, because outputs read engine sinks.

## Acceptance criteria

- [x] Tap shows the bar and it hides after 3 s idle; with a trackpad, hovering the bottom zone shows it
- [x] The bar has no clipped controls at full screen, 1/2 Split View and a small Stage Manager window (simulator screenshots)
- [ ] The iPadOS menu bar lists Video/File/Pro commands, and ⌘S, ⌘R and M (mute) work with a hardware keyboard
- [x] Settings opens as a sheet and changes persist across relaunch
