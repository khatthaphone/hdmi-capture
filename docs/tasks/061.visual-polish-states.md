## Objective

Make every non-live state look designed and consistent on Mac and iPad: scanning, connect-a-card, permission, connecting, recovering, failed, no signal and paused share one layout (illustration, title, one-line explanation, action), and toasts use the right icon and tone.

## Relevant files / modules

- `Apps/Shared/ContentView.swift` — StatusOverlay, NoSignalOverlay, Banner, toast
- `Apps/Shared/PauseIllustration.swift` — the drawn-illustration pattern to extend
- `docs/research/ux-review.md` — the issues assigned to this task

## Steps

1. Create a shared `StateCard` view (illustration slot, title, message, optional buttons) and move every state onto it.
2. Draw small illustrations in the PauseIllustration style for: connect a card (iPad and Mac cable variants), camera permission, no signal or HDCP (source → card → screen with a break), failed.
3. Toasts: success = checkmark (green tint), warning = triangle (orange), info = neutral. Fix "Nothing live to record" and similar, which currently show a checkmark.
4. Keep overlays out of outputs (they're SwiftUI only, so no change). Check that record3s and Save Recent are unaffected.

## Acceptance criteria

- [ ] Every state in ux-review.md's list renders with StateCard (screenshots before and after in `docs/research/ux/shots/`)
- [ ] Error and warning toasts no longer show a success checkmark
- [ ] `make build`, `make build-ipad` and the tests pass
