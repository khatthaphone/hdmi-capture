**Status:** in-progress
**Phase:** Phase 2: macOS polish
**Depends on:** 010
**Complexity:** simple — suggested model: Claude Code → haiku · Codex → luna

## Objective

Extend the stats overlay with capture→display latency estimate and per-stage timings, to tune against Dongled.

## Relevant files / modules

- `MetalRenderer.swift` — presentation timestamps
- `CaptureEngine.swift` — sample buffer PTS
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. Compute host-time delta between sample buffer PTS and `MTLDrawable` presented time.
2. Show avg/p95 over last 2 s; add `os_signpost` intervals for capture, upload, draw.

## Acceptance criteria

- [x] HUD shows latency numbers updating each second
- [ ] Signposts visible in Instruments Points of Interest
