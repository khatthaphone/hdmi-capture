## Objective

Brightness/contrast/saturation/gamma/sharpen with presets (Standard, Game, Cinema, Vivid) — parity with SyncZero/CapturePlay.

## Relevant files / modules

- `MetalRenderer.swift` — extend fragment shader + optional sharpen pass
- `Presets.swift` — ImageAdjustments struct (decodeIfPresent)
- `SettingsView.swift` — Picture section
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Add ImageAdjustments {brightness, contrast, saturation, gamma, sharpness} applied after YCbCr→RGB.
2. Sharpen = second pass unsharp mask (only when sharpness > 0 to keep latency path minimal).
3. Presets as named value sets; 'Reset' restores Standard.
4. Offscreen render tests: identity settings leave color bars unchanged (±1).

## Acceptance criteria

- [x] Identity adjustments produce identical output to 008's tests
- [x] Each slider visibly changes the image live
- [x] GPU time with sharpen on stays < 2 ms at 1080p
