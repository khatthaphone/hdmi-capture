## Relevant files / modules

- `tools/release/` — new scripts
- `project.yml` — signing settings

## Steps

1. Release config: hardened runtime, sandbox, Developer ID signing (team ID via env/xcconfig, not committed).
2. Script: archive → export → `notarytool submit --wait` → staple → create DMG.
3. Document prerequisites (Apple Developer account, app-specific password/keychain profile) in `docs/release.md`.
4. If no Developer account yet: produce ad-hoc signed build and mark task blocked on notarization step.
