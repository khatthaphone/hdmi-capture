## Objective

The Settings window and the persistence behind it, matching `SettingsView` and per-device presets on Mac.

## Relevant files / modules

- `docs/spec.md` §13 — Windows requirements
- `docs/research/windows.md` — research (2026-10-22)

- `Apps/Shared/Model/ViewerPrefs.swift`

## Steps

1. WinUI Settings window (NavigationView): General, Video (device, format pin, scale, filter, colour range/matrix), Audio (device override, output, delay, channel mode), Image (adjustments), Profiles, About (version, licences from `THIRD-PARTY.md`).
2. Prefs as source-generated JSON in LocalAppData with atomic writes; per-device presets keyed by the stable key; console profiles as on Mac.
3. Format picker lists the native types with fps; pinning a format survives replug.
4. Ctrl+, opens it; it's also in the tray menu and the context menu.

## Acceptance criteria

- [ ] Every setting persists across restart and applies live without restarting capture (except format changes)
- [ ] Per-device presets restore when that card is plugged back in
- [ ] Settings are fully keyboard- and Narrator-navigable
