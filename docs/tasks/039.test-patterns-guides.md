# 039 — Test patterns & frame guides

**Status:** done
**Phase:** Phase 7: Viewer features (free)
**Depends on:** 008
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Pro-monitoring basics that no Mac viewer has (gap #7), useful for checking a display chain and framing shots from cameras like the a6600.

## Relevant files / modules

- `MetalRenderer.swift` — overlay pass
- `Packages/CaptureCore/Sources/CaptureCore/TestPattern.swift` — new pixel-buffer generators
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Generated patterns (SMPTE bars, grid, gray ramp, resolution chart) selectable when no device or from the View menu.
2. Guides overlay: rule of thirds, center cross, 90/80 % safe areas, aspect masks (2.39, 1.85, 4:3, 9:16, 1:1) with adjustable opacity.
3. Guides drawn in the GPU pass (no extra windows).

## Acceptance criteria

- [x] Bars pattern rendered through the normal pipeline matches 008's expected colors
- [x] Each guide toggles independently and scales with the video rect, not the window
