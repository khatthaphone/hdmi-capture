## Objective

Produce the numbers the ADR needs: glass-to-glass latency, sustained fps, memory and thermals per device and format. Needs hardware: an Android device with USB-C host mode + the UGREEN cards + an HDMI source. If none is available, set `blocked` and ask the user; don't fake results.

- `docs/spec.md` §12 — Android requirements
- `docs/research/android.md` — research
- `docs/research/devices/ipad-pro-11-2g.md` — report format to mirror

## Steps

1. DEBUG `qaSoakMinutes` intent extra writing a CSV (fps, drops, memory, thermal status/headroom, audio buffer) to app files; `make android-soak` pulls it.
2. Latency: 240 fps phone camera filming a flashing source next to the device; ≥ 20 samples per format.
3. 15-minute soak per device at its best format.
4. Write `docs/research/devices/<device>-android.md` per device.
