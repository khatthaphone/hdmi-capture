## Steps

1. `HDMICaptain.Windows.slnx` with `src/HDMICaptain.Core` (net10.0), `src/HDMICaptain.Media` (net10.0-windows10.0.22621), `src/HDMICaptain.App` (WinUI, Windows App SDK 2.5.x pinned in `Directory.Packages.props`), `tests/HDMICaptain.Core.Tests` and `tests/HDMICaptain.Media.Tests` (xUnit). Central package management; `Nullable` + `TreatWarningsAsErrors` on.
2. Add CsWin32 (`NativeMethods.txt`) and Vortice.Direct3D11/DXGI/D3DCompiler to Media. Prove both with a trivial call (create a D3D11 device on WARP in a test).
3. `native/vcpkg.json` manifest with libjpeg-turbo for x64 and arm64. A build step copies `turbojpeg.dll` next to the app. Licence notices go in `Apps/Windows/THIRD-PARTY.md`.
4. App: a single window that says "HDMI Captain", app icon from `Design/AppIcon`, dark theme. Debug runs unpackaged (`WindowsPackageType=None`); Release builds an MSIX (`make win-package`). Placeholder identity `com.example.hdmicaptain`, same as Apple.
5. Parse the Apple QA arguments (`-testPattern`, `-qaAction`, `-qaShowStats`, `-qaPinControls`, `-qaSoakMinutes`, `-debugUnlockPro`) into a `LaunchOptions` record, honoured in DEBUG only.
6. Makefile targets: `win-build` (dotnet build), `win-test` (dotnet test), `win-run` (build + launch with `WIN_ARGS`), `win-package` (Release MSIX). `.gitignore` for `bin/`, `obj/`, `vcpkg_installed/`, `AppPackages/`.

## Acceptance criteria

- [x] `make win-build` and `make win-test` succeed from a clean clone on this PC without opening Visual Studio
- [x] `make win-run` shows the window; `make win-package` produces an installable MSIX (sideloaded with a dev certificate) — signed by `CN=HDMI Captain Dev`; installing it needs the one-time admin trust step the cert script prints
- [x] CLAUDE.md lists the Windows commands and layout
