# 048 — Custom control-bar glyphs

**Status:** todo
**Phase:** Phase 7: Viewer features (free)
**Depends on:** 047
**Complexity:** simple — suggested model: Claude Code → haiku · Codex → luna

## Objective

SF Symbols cover most of the bar. Generate custom template glyphs only where SF has nothing good (HDMI input, Save Recent, maybe Go Live), via Codex CLI image generation, and keep the SF Symbol fallback if the generated glyph doesn't sit well next to SF Symbols.

## Relevant files / modules

- `Apps/macOS/Assets.xcassets` — imagesets, "Render As Template"
- `project.yml` — include the asset catalog
- `Apps/macOS/Sources/ControlBar.swift` — swap symbols

## Steps

1. Generate monochrome line icons (transparent, 2 px stroke, SF Symbols style) with `codex-image:generate`.
2. Threshold/clean to template PNGs at 1×/2×/3×.
3. Add to the asset catalog; reference from the bar.

## Acceptance criteria

- [ ] Glyphs read clearly at 16–18 pt on the dark bar in light and dark mode
- [ ] Optical weight matches neighbouring SF Symbols (side-by-side screenshot)
