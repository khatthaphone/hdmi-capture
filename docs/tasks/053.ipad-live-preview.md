# 053 — iPad live preview (Metal view, aspect, rotation)

**Status:** in-progress
**Phase:** Phase 3: iPadOS
**Depends on:** 051, 052
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Show the live card picture on iPad through the existing `MetalRenderer`, with the same scale modes and no mirroring. This is the first time the iPad app shows a capture card's picture.

## Relevant files / modules

- `Apps/macOS/Sources/MetalLayerView.swift` — NSView + CAMetalLayer; write a `UIViewRepresentable` twin (`Apps/iPadOS/Sources/MetalLayerView.swift`)
- `Packages/CaptureCore/Sources/CaptureCore/MetalRenderer.swift` — check `420f` (full range) is handled as well as `420v`; iPadOS converts MJPEG cards to 420f
- `Packages/CaptureCore/Sources/CaptureCore/CaptureEngine.swift` — session config; set `automaticallyConfiguresApplicationAudioSession = false` on iOS (054 relies on it)
- `docs/research/ipados.md` — platform facts and sources for this phase

## Steps

1. Write `MetalLayerView` for UIKit: a UIView with `layerClass = CAMetalLayer`, `contentsScale` = screen scale, and drawable size updated in `layoutSubviews`.
2. Wire `DeviceSession`/`ViewerModel` from `Apps/Shared` to the view, and pick the first card on launch, as on Mac.
3. Check the renderer handles both video-range and full-range 4:2:0. Add a test with a synthetic full-range buffer if the shader branches on it.
4. Handle rotation: the picture stays upright and letterboxed in landscape and portrait. Never apply camera mirroring.
5. Show signal states (no signal / HDCP / no card) using the existing `SignalAnalyzer` overlay.
6. Set up and document Xcode wireless debugging, because the USB-C port holds the card.

## Acceptance criteria

- [ ] The simulator shows the test pattern through the new Metal view in every scale mode
- [x] On a USB-C iPad: live 1080p60 (or the card's best mode) with the stats HUD showing ~60 fps and no dropped-frame growth over 5 minutes (**hardware**)
- [ ] Rotating the iPad keeps the picture upright, unmirrored and correctly letterboxed
