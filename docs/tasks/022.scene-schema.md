**Status:** todo

## Objective

Define the data contract for scenes/sources/transforms/audio-mix/output profiles shared by Apple, Android and Windows implementations. High blast radius: every platform builds on it.

## Relevant files / modules

- `docs/spec.md` — §4 'specs as data'
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. JSON Schema (draft 2020-12) for: scene collection, scene, source (hdmi, camera, screen, image, text, color, browser), transform (pos/scale/rotation/crop), filters (chroma key, color correct), audio track (gain, mute, sync offset), output profile (RTMP/SRT url, bitrate, resolution, fps, encoder).
2. Versioning field + migration rules.
3. Example files in `docs/examples/`; validator script in `tools/`.
4. Write ADR `docs/adr/0001-scene-schema.md`.

## Acceptance criteria

- [ ] Schema validates all examples; invalid examples rejected (test script)
- [ ] ADR documents versioning/migration policy
- [ ] Reviewed by user before Phase 4 implementation starts (log entry)
