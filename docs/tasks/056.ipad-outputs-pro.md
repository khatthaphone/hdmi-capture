# 056 — iPad screenshot, recording, Save Recent & Pro

**Status:** in-progress
**Phase:** Phase 3: iPadOS
**Depends on:** 054, 055
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Bring the outputs to iPad: screenshot and Copy Frame (free), recording and Save Recent (Pro via StoreKit 2), saved to Photos or the app's Files folder.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/Recorder.swift`, `RollingRecorder.swift` — AVAssetWriter; should run unchanged on iOS
- `Apps/Shared/Store/EntitlementStore.swift` — StoreKit 2; add the `.storekit` file to the iPad scheme
- `Apps/macOS/HDMICaptain.storekit` — share it or copy it for the iPad scheme
- `Apps/macOS/Sources/AppModel.swift` — where recordings go on Mac (Movies folder); iPad uses Documents + an optional Photos export

## Steps

1. Screenshot: PNG of `MetalRenderer.currentFrame` → Photos (add-only permission) or Documents, chosen in Settings. Copy Frame → `UIPasteboard`.
2. Recording: write to `Documents/Recordings/`, visible in the Files app, with optional "Save to Photos" when it stops. Keep the codec choice (HEVC/H.264).
3. Save Recent: the same rolling buffer, with the disk estimate shown in Settings.
4. Pro gating only through `EntitlementStore.gate`. Free features are never gated. Use the same product ID as on Mac, so one purchase covers both if it's a universal purchase (**decide in 058 / at App Store setup**; note it in the spec).
5. If the app goes to the background while recording, finalise the file cleanly (021 handles resume).

## Acceptance criteria

- [x] The screenshot reaches Photos (or Files) and holds only the picture, with no bar or overlays (check the image)
- [x] A 30 s HEVC recording plays in Photos/Files at the card's resolution and frame rate, with audio (**hardware**)
- [x] Save Recent 15 s produces a 15 s clip (**hardware**)
- [ ] With Pro locked, Record and Save Recent open the upgrade sheet, and screenshot stays free; the StoreKit local tests pass
