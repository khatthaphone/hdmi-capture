## Objective

Implement the business model: free viewer + one-time 'HDMI Captain Pro' non-consumable unlocking recording, replay buffer, streaming and virtual camera. Critical: money and access control.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/Entitlements.swift` — ProFeature enum + EntitlementProviding protocol
- `Apps/macOS/Sources/Store/StoreKitEntitlements.swift` — StoreKit 2 implementation
- `Apps/macOS/HDMICaptain.storekit` — local StoreKit configuration for testing without an Apple account
- `docs/adr/0004-monetization.md` — new ADR
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. ADR: free viewer, one-time non-consumable `<bundle>.pro`; StoreKit requires Mac App Store distribution; a license-key provider (e.g. Paddle/Lemon Squeezy) can implement the same protocol later for direct sales.
2. `ProFeature` = recording, replayBuffer, streaming, virtualCamera. `EntitlementStore` (@Observable) exposes `isUnlocked(_:)`.
3. StoreKit 2: load product, purchase, `Transaction.currentEntitlements` on launch, listen to `Transaction.updates`, honor revocation, only trust `.verified` results.
4. Add .storekit config to the scheme for local testing; DEBUG-only override toggle.
5. Tests with StoreKitTest (SKTestSession): purchase, restore, refund/revoke.

## Acceptance criteria

- [ ] ADR committed
- [ ] Purchase / restore / revoke flows pass in SKTestSession tests
- [ ] Feature checks return false before purchase and true after, across relaunch
- [ ] No unverified transaction ever unlocks Pro
