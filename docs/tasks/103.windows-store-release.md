## Steps

1. Partner Center account (individual, free) — **needs the user**: identity verification, publisher name per Policy 7.20, reserved app name.
2. MSIX: real identity from Partner Center, `runFullTrust`, `webcam` + `microphone` capabilities, x64 + ARM64 bundle, `make win-package` producing the upload.
3. Pro durable add-on in Partner Center; a hidden flight to run the real-purchase test from 099 (buy, restore, refund).
4. Listing: description and screenshots (from `-testPattern` + `-qaAction screenshot`), privacy policy URL (mandatory), IARC questionnaire, third-party notices.
5. Submit for certification; after it passes, confirm `winget install` by Store ID works.
