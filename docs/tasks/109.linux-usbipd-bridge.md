## Objective

Script the handover of a capture card between Windows and WSL so it's one command each way, with the udev rules in place first. 108, 111 and 113 depend on this.

- Memory note: the user often works remotely; elevation (UAC) needs them at the PC

## Steps

1. The user installs usbipd-win once (`winget install --interactive --exact dorssel.usbipd-win`) and runs `usbipd bind --busid <id>` elevated for each card. Add both to the hardware-check list instead of blocking other work.
2. `tools/linux/wsl-card.ps1 status|attach|detach [-Name UGREEN-25854] [-Auto]`: finds the bus id by VID:PID, attaches with `--wsl` (`--auto-attach` with `-Auto`), detaches, and prints where the card is now. Make targets: `linux-card-attach` / `linux-card-detach`.
3. Inside WSL: `tools/linux/99-hdmicaptain.rules` (capture VID:PIDs → `power/control=on`; group `video`), installed by `setup-wsl.sh`. `modprobe uvcvideo snd-usb-audio` if the nodes don't appear. Check `udevadm monitor` sees attach and detach.
4. Document that attaching takes the card from Windows (our Windows app shows Disconnected) and that detaching hands it back (the Windows app recovers by itself).

## Acceptance criteria

- [ ] `wsl-card.ps1 attach` makes `/dev/video*` appear in WSL; `detach` returns the card and the Windows app goes live again without a restart
- [ ] udev add/remove events are seen in WSL on attach/detach
- [ ] The one-time admin steps are written down in CLAUDE.md and the hardware-check memory
