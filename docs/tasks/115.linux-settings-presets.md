## Objective

A settings window with the same options and the same prefs JSON keys as Windows/Apple, stored under `$XDG_CONFIG_HOME/hdmicaptain/`.

## Relevant files / modules

- `docs/spec.md` §14 — Linux requirements
- `docs/research/linux.md` — research (2026-10-23)
- `Apps/Windows/src/HDMICaptain.App` settings (task 095)
- `Apps/Windows/src/HDMICaptain.Core/ViewerPrefs.cs`, `PresetStore.cs`, `Profiles.cs`

## Steps

1. `Adw.PreferencesWindow`: video device, audio device (pairing override), format (auto or pinned; shows requested vs actual), scale/filter/colour, image adjustments, profiles, per-device presets.
2. Prefs persistence reuses the Core JSON models (source-generated). Atomic write (temp + rename). QA flags never persist.
3. Changes apply live without restarting capture unless the format changes.

## Acceptance criteria

- [x] Settings round-trip through the JSON file with the same keys as Windows (test)
- [ ] Switching format or device from settings works on the live card
- [x] QA flags don't change the prefs file (test)
