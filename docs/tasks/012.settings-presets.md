# 012 — Settings, device/format pickers, per-device presets

**Status:** done
**Phase:** Phase 1: macOS MVP viewer
**Depends on:** 010, 009
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Settings UI and persistence so users can override auto choices, remembered per device `uniqueID`.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/Presets.swift` — new
- `Apps/macOS/` — Settings scene
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. `Presets` store (Codable, `UserDefaults` or JSON in Application Support) keyed by video `uniqueID`: format pin, scale, filter, color range, audio device, volume.
2. SwiftUI `Settings` scene + popover in window: video device, audio device, format (from FormatSelector candidates), scale/filter/color, volume.
3. Changes apply live without restarting the app.

## Acceptance criteria

- [x] Changing format live switches within 1 s, no crash
- [x] Presets restored when the same dongle is replugged; a different dongle gets its own defaults
- [x] Unit tests for Presets encode/decode and migration of a missing key
