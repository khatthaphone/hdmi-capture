## Objective

Tasks 018 and 034 on Windows: one window per card, and a grid of every card in one window drawn into a single swap chain.

## Relevant files / modules

- `docs/spec.md` §13 — Windows requirements
- `docs/research/windows.md` — research (2026-10-22)
- Tasks 018, 034 and `Apps/macOS/Sources/MultiViewGrid.swift`, `Apps/Shared/Model/DeviceSession.swift`

## Steps

1. One `DeviceSession` (controller + renderer + audio) per window; "Open in new window" per card; `-qaAction openCards`.
2. Grid window composes all sessions into one swap chain (viewports), with an audio source picker; `-qaAction grid`.
3. Each card keeps its own presets; closing a window stops only that card.

## Acceptance criteria

- [ ] Two cards show at the same time in two windows and in the grid (log fps per card)
- [ ] Unplugging one card doesn't disturb the other
