## Objective

Prove the primary capture path: open the UGREEN cards through the USB Host API, stream uncompressed and MJPEG formats, and measure frame delivery. Needs hardware: an Android device with USB-C host mode + the UGREEN cards + an HDMI source. If none is available, set `blocked` and ask the user; don't fake results.

## Steps

1. Build libusb 1.0.30 (shared, LGPL notice) and libuvc 0.0.8 from source via CMake; 16 KB aligned.
2. Kotlin: device list, attach filter (class 14), runtime permissions, USB permission PendingIntent (`FLAG_MUTABLE`, explicit); pass the fd to native `libusb_wrap_sys_device`.
3. Dump descriptors + link speed for both cards to `docs/research/devices/<card>-android.json` (the real wire formats macOS hides).
4. Stream each format into the 071 renderer (uncompressed directly; MJPEG via a stub decode until 074). Record fps, dropped/short frames, transfer settings.
5. Unplug/replug while streaming: no crash, clean re-open. Claim only UVC interfaces.
