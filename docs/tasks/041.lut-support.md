# 041 — LUT support (.cube)

**Status:** in-progress
**Phase:** Phase 7: Viewer features (free)
**Depends on:** 036
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Apply creative or log-to-Rec.709 LUTs (e.g. Sony S-Log3 from the a6600) to the preview.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/CubeLUT.swift` — new parser
- `MetalRenderer.swift` — 3D texture sampling stage
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Parse .cube 1D/3D (sizes up to 65), DOMAIN_MIN/MAX; reject malformed files with a clear error.
2. Upload as 3D texture; apply after image adjustments with intensity slider.
3. Per-device LUT selection stored via security-scoped bookmark (sandbox).

## Acceptance criteria

- [x] Parser tests: identity, 33-point sample, malformed file
- [x] Identity LUT leaves output unchanged (±1)
- [ ] LUT persists across relaunch in the sandboxed build
