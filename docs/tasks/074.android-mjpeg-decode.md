## Objective

Decode MJPEG at 1080p60 fast enough on mid-range phones; the format USB 2.0 ports force. Needs hardware: an Android device with USB-C host mode + the UGREEN cards + an HDMI source. If none is available, set `blocked` and ask the user; don't fake results.

- `docs/spec.md` §12 — Android requirements

- `docs/research/android.md` §3

## Steps

1. Build libjpeg-turbo 3.2 from source (NEON); `tj3DecompressToYUV8` into AHardwareBuffer/planar buffers; upload as R8 planes.
2. Two-thread decode pipeline; drop late frames rather than queue.
3. Probe `MediaCodecList` for a vendor MJPEG decoder and compare if present.
4. Benchmark decode ms (p50/p95) and CPU/thermal over 5 min at 1080p60 on each device.

## Acceptance criteria

- [ ] 1080p60 MJPEG shown at ≥ 58 fps on at least one device, numbers logged
- [ ] Benchmark table in the research doc
