# 104 — Optional: virtual camera test source (MFCreateVirtualCamera)

**Status:** in-progress
**Phase:** Phase 6: Windows
**Depends on:** 089
**Complexity:** critical — suggested model: Claude Code → opus/fable · Codex → sol

## Objective

Build a C++ COM media source that Windows 11 publishes as a camera, generating test patterns. It lets the MF capture path, hot-plug and recovery be exercised without a card, and prototypes the later Pro virtual camera (026). Optional: skip it if the real cards stay plugged in.

## Relevant files / modules

- `docs/spec.md` §13 — Windows requirements
- `docs/research/windows.md` — research (2026-10-22)
- Microsoft `Windows-Camera/Samples/VirtualCamera`, `smourier/VCamSample` (MIT)
- `docs/research/windows.md` §9
- Task 026 — Apple virtual camera

## Steps

1. C++ (CMake or vcxproj under `Apps/Windows/native/VirtualCamera`) media source DLL: NV12 + YUY2 + MJPG types at 720p60/1080p60, frame counter burned into the pattern.
2. Register for `CurrentUser`; a DEBUG app command creates/removes it with `MFCreateVirtualCamera` (Session lifetime), off the UI thread.
3. Use it in a scripted test: create → app picks it up → remove → app recovers when it reappears.
4. Record whether a COM server registered only inside the MSIX is visible to Frame Server (the open risk for the Pro feature).

## Acceptance criteria

- [ ] The app shows the virtual camera's pattern through the real MF path
- [ ] Create/remove cycles drive the controller through Scanning → Live → Recovering → Live
- [ ] MSIX visibility result logged for task 026/ADR 0003

  - Frames: SMPTE 75 % bars (CaptureCore's `smpteBars` layout) on the CPU into the allocator's buffers, with an 8-digit 7-segment frame counter drawn into the Y/UV planes. A pacer thread with a high-resolution waitable timer answers `RequestSample` at 60 Hz; sample time `MFGetSystemTime()`, duration 166 667, `MFSampleExtension_Token`/`CleanPoint`/`Discontinuity` (first sample). `SetD3DManager` is accepted but ignored (CPU frames).
  - `vcam status | add [--seconds N] [--grab F] | list | grab [--frames F] [--format nv12|yuy2] [--size WxH] | selftest`.
