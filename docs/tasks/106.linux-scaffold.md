## Objective

Create `Apps/Linux` as a command-line-buildable .NET 10 solution with the layout from spec §14.9. It references `HDMICaptain.Core` as is and opens a libadwaita window, so every later Linux task has a home.

## Relevant files / modules

- `docs/spec.md` §14 — Linux requirements
- `docs/research/linux.md` — research (2026-10-23)
- `docs/spec.md` §14.9 — layout
- `Apps/Windows/` and task 086 — how the Windows scaffold was done (central package versions, `global.json` for Microsoft.Testing.Platform, `LaunchOptions`)
- `Apps/Windows/src/HDMICaptain.Core/` — referenced, not copied
- Gir.Core docs/samples: https://gircore.github.io/

## Steps

1. `Apps/Linux/HDMICaptain.Linux.slnx` with `src/HDMICaptain.Linux.Media` (net10.0, `AllowUnsafeBlocks`, Linux-only P/Invoke), `src/HDMICaptain.Linux.App` (Gir.Core `GirCore.Adw-1` + `GirCore.Gtk-4.0`, versions pinned centrally) and `tests/HDMICaptain.Linux.Media.Tests` (xUnit v3). `Nullable` and `TreatWarningsAsErrors` on. A `ProjectReference` to `../Windows/src/HDMICaptain.Core`.
2. Check that Gir.Core supports the distro's GTK/libadwaita versions (Ubuntu 24.04: GTK 4.14, Adw 1.5). If the newest Gir.Core needs newer libraries, pin an older one or log the minimum distro version. Log the choice.
3. App: an `Adw.Application` (id `com.example.HDMICaptain`) with one dark window titled "HDMI Captain", the icon from `Design/AppIcon`, and a `.desktop` file for dev runs. Parse the shared QA arguments with the existing `LaunchOptions` (DEBUG only).
4. Logging to `$XDG_STATE_HOME/hdmicaptain/logs/capture.log`, in the same line format as Windows.
5. Make targets from 105 build and run this solution; `linux-test` runs the Core tests and the Linux tests.
6. `.gitignore` entries for `Apps/Linux/**/bin`, `obj` and any native build dir.

## Acceptance criteria

- [ ] `make linux-build` and `make linux-test` pass from a clean clone (on WSL)
- [ ] `make linux-run` shows the libadwaita window on the Windows desktop through WSLg; a screenshot is checked and then deleted
- [ ] `HDMICaptain.Core` is referenced, not copied, and the Windows build (`make win-build && make win-test`) is still green
- [ ] CLAUDE.md layout section lists `Apps/Linux/`
