## Steps

1. Signal status: no signal / HDCP detection via `SignalAnalyzer` on a 160×90 GPU downsample, hold last frame, requested vs actual mode.
2. Stats HUD (`-qaShowStats`): input mode/fps, render fps, drops, decode ms, present mode.
3. Screenshot: WIC PNG from the pass-1 texture to `Pictures\HDMI Captain` + clipboard (Ctrl+Shift+S, control bar button, `-qaAction screenshot|copy`).
4. Window size presets (50/100/200 %, actual pixels; `-qaAction size50|actualPixels`) and a tray icon with the menu-bar-extra actions (show/hide, mute, input, screenshot, quit).
5. Latency test UI around the 092 probe (results dialog, as on Mac).

- [ ] Tray icon actions work, and the app can run with the window hidden while capture continues
