# 035 — Built-in latency test

**Status:** in-progress
**Phase:** Phase 7: Viewer features (free)
**Depends on:** 010, 017
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Back the 'low latency' claim with a number (gap #1, unique in the market): loop the Mac's own HDMI output into the capture card and measure flash-to-arrival and flash-to-display times.

## Relevant files / modules

- `Apps/macOS/Sources/LatencyTest/` — new: test window + controller
- `MetalRenderer.swift` — presented-time callbacks (from 017)
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Guide the user: connect Mac HDMI out → capture card; pick the external NSScreen.
2. Show a borderless full-screen window on that screen that flips black/white; record each flip's host time from the drawable's presentedHandler.
3. On the capture side, detect the luma transition per frame (reuse SignalAnalyzer sampling) and record arrival host time; renderer records present time for that frame.
4. Run 30 flips; report median and p95 for capture latency and total glass-to-glass (± one refresh), with format and card name.
5. Save results as JSON + markdown in docs/research/latency/ when run from a dev build.

## Acceptance criteria

- [ ] Test completes in < 30 s and shows median/p95 in ms
- [ ] Repeated runs on the same setup agree within one frame interval
- [ ] Results recorded for both UGREEN cards in docs/research/latency/
