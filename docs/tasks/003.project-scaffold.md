## Steps

1. `git init`; add `.gitignore` (Xcode, SwiftPM, DerivedData, .DS_Store).
2. Create `Packages/CaptureCore` Swift package (platforms: macOS 14, iOS 17) with empty `CaptureCore` target + `CaptureCoreTests`.
3. Create `project.yml` (XcodeGen) with `HDMICaptain-macOS` app target in `Apps/macOS`, depending on CaptureCore; universal binary; bundle id placeholder `com.example.hdmicaptain`.
4. Add Info.plist usage strings (`NSCameraUsageDescription`, `NSMicrophoneUsageDescription`) and entitlements (sandbox, device.camera, device.audio-input).
5. Minimal SwiftUI `App` with an empty window.
6. Add `Makefile` (or `scripts/`) with `make gen`, `make build`, `make test`.
7. Add a `CLAUDE.md` describing layout, build commands, and pointing to `docs/spec.md` + `docs/tasks/000.INIT.md`.

## Acceptance criteria

- [ ] `make gen && make build` succeeds from a clean clone (requires `brew install xcodegen`, documented)
- [ ] `make test` runs CaptureCore tests (one placeholder test passes)
- [ ] App launches and shows an empty window
- [ ] Entitlements file contains sandbox + camera + audio-input keys
