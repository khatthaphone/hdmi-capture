## Objective

Small Swift command-line tool that lists every external video/audio capture device and all their formats, so FormatSelector defaults (task 005) are grounded in real dongle data.

## Relevant files / modules

- `tools/device-inventory/` — new Swift package (executable)
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. Create `tools/device-inventory` as a Swift package executable (macOS 14+).
2. Use `AVCaptureDevice.DiscoverySession(deviceTypes: [.external, .microphone], mediaType: nil, position: .unspecified)`.
3. For each video device print: localizedName, uniqueID, modelID, manufacturer, transportType, and each format (dimensions, FourCC media subtype, fps ranges).
4. Support `--json` output.
5. Run against the user's dongle(s); commit output to `docs/research/devices/<model>.json`.

## Acceptance criteria

- [ ] `swift run device-inventory` prints devices and formats; `--json` emits valid JSON
- [ ] At least one real dongle's output committed under `docs/research/devices/`
- [ ] Tool needs camera permission prompt handled (runs from Terminal with TCC prompt)
