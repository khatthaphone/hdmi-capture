## Objective

Make the Ubuntu-24.04 WSL distro on the Windows dev PC a one-command Linux dev box: packages installed, the tree synced to ext4, and a GTK4 window showing on the Windows desktop with GPU GL. Every later Linux task builds and runs here. This task needs no capture hardware.

## Steps

1. `tools/linux/setup-wsl.sh` (idempotent): apt packages `build-essential cmake ninja-build pkg-config rsync libgtk-4-dev libadwaita-1-dev libturbojpeg0-dev libpulse-dev libasound2-dev libudev-dev v4l-utils mesa-utils pulseaudio-utils`, plus the .NET 10 SDK (Ubuntu package or `dotnet-install.sh` into `~/.dotnet`). `sudo` needs the user's password: ask the user to run it once (`! wsl -d Ubuntu-24.04 -- sudo bash tools/linux/setup-wsl.sh`), or get their OK to use `wsl -u root`.
2. `tools/linux/wsl-sync.sh`: rsync the working tree to `~/src/hdmi-capture`, leaving out `bin/ obj/ .build/ .git/ vcpkg_installed/`. Time a cold and a warm sync. Compare against building in place on `/mnt/d` with `--artifacts-path ~/.cache/hdmicaptain`. Keep the faster one and log the numbers.
3. Makefile: `linux-setup`, `linux-sync`, `linux-build`, `linux-test`, `linux-run LINUX_ARGS=`, `linux-logs`. On Windows (Git Bash) each wraps `wsl -d Ubuntu-24.04 --cd ~/src/hdmi-capture -- make …` after a sync. On Linux they run directly. `LINUX_DISTRO=` overrides the distro.
4. GPU check: `glxinfo -B` / `eglinfo` must report the D3D12 (RTX 5070 Ti) renderer, not llvmpipe. Record the GL and GLES versions. Run `gtk4-demo` (or a 20-line GTK4 test) under `GSK_RENDERER=ngl`, `gl` and `cairo`, and pick the WSL default.
5. Window plumbing from Windows: find the WSLg window (owner `msrdc.exe`). Bring it to the front with the SwitchToThisWindow snippet. Screenshot it with `PrintWindow` through `shot.ps1`, and log whether RAIL windows capture or come back black. HiDPI: check how a 125 % Parsec display renders, and set `.wslgconfig` only if needed.
6. Audio check: `paplay` a test tone through `PULSE_SERVER` and hear/record it on Windows.
7. Run `HDMICaptain.Core.Tests` (from `Apps/Windows/tests`) inside WSL: the pure Core must pass on Linux as is, so this is a free cross-platform check. Fix any path or culture assumptions it exposes.
8. Document the loop in `CLAUDE.md` (Linux commands, WSL notes) and in `docs/research/linux.md` §7 (measured numbers).

## Acceptance criteria

- [ ] `make linux-setup` and `make linux-build` succeed from Git Bash on the dev PC; `make linux-test` runs `HDMICaptain.Core.Tests` green inside WSL

- [ ] A GTK4 window started from Git Bash appears on the Windows desktop, can be brought to the front, and a window screenshot method that works is recorded
