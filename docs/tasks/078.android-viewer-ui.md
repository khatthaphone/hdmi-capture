## Steps

1. Dark Material 3 theme with the icon's navy/gold accents; `StateCard` equivalent and all states incl. Android-only ones; Connection Help with Android steps.
2. Control bar: tap toggles (3 s auto-hide), pointer hover reveal, right-click menu; input picker, volume/mute, screenshot, Record/Save Recent (Pro-locked), view options.
3. Edge-to-edge + immersive, keep screen on while live, PiP auto-enter, predictive back, keyboard shortcuts (Mac set) + shortcut helper.
4. Strings in `strings.xml`; content descriptions for TalkBack.
5. Compose UI tests for the states; screenshots at phone, tablet and desktop-window sizes into `docs/research/android/`.

## Acceptance criteria

- [ ] Every state from spec §12.7 has a screen and a UI test
- [ ] Bar fits at 360 dp wide and in a desktop window
- [ ] No overlay pixels in a GL screenshot
