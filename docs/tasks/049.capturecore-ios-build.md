## Objective

Make the shared package compile for iOS and keep it that way, so every later iPad task starts from a green build. A survey on 2026-10-21 found exactly one error: `AVCaptureDevice.transportType` is unavailable on iOS.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/AVDeviceProvider.swift:17` — `transportType`, guard with `#if os(macOS)`
- `Makefile` — add an iOS check target
- `Packages/CaptureCore/Tests/` — the 93 existing tests

## Steps

1. Guard `transportType` with `#if os(macOS)`; on iOS set `transport` to `"USB"` for `.external` devices.
2. Add `make build-ios-core`: `xcodebuild -scheme CaptureCore -destination 'generic/platform=iOS' build`.
3. Add `make test-ios-core`, which runs the CaptureCore tests on an iPad simulator (`-destination 'platform=iOS Simulator,name=iPad Pro …'`). Skip or `#if` the macOS-only tests (CoreAudio device listing) and say why.
4. Document both targets in `CLAUDE.md` → Commands.

## Acceptance criteria

- [ ] `make build-ios-core` succeeds with no errors
- [ ] `make test-ios-core` passes on an iPad simulator, and any skipped tests are listed in the log with a reason
- [ ] `make test` (macOS) still passes 93/93
