**Status:** done

**Depends on:** none

## Objective

Ship the selected device-network icon consistently on iOS, iPadOS, macOS, and Android. The icon has to remain legible at 16 px and use a full-bleed background on every platform.

## Relevant files / modules

- `Design/AppIcon/master-1024.png` — canonical full-bleed icon
- `Design/AppIcon/mac-1024.png` — canonical macOS source
- `Apps/Shared/Assets.xcassets/AppIcon.appiconset` — iOS, iPadOS, and macOS icon sizes
- `Apps/Shared/Assets.xcassets/AppLogo.imageset` — in-app logo sizes
- `Apps/Android/app/src/main/res/mipmap-xxxhdpi/ic_launcher_foreground.png` — Android adaptive foreground
- `Apps/Android/app/src/main/res/values/themes.xml` — Android adaptive background color

## Steps

1. Keep the selected composition: Apple/mobile inputs on the left, a central HDMI capture hub, and PC/controller/handheld/camera devices on the right.
2. Generate a full-bleed 1024 px blue master with no text, border, transparent corners, or white margins.
3. Derive all Apple, in-app, and Android launcher assets from the master.
4. Verify pixel dimensions, color/alpha requirements, and platform builds.

## Acceptance criteria

- [x] iOS, iPadOS, macOS, and Android use the selected icon
- [x] The full-bleed 1024 px master has no alpha channel
- [x] All required derived sizes are present
- [x] Platform builds succeed without asset-catalog errors
