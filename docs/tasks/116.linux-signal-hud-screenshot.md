## Steps

1. Signal status from `SignalMonitor` on pass-1 samples (no signal, black, frozen), hold last frame.
2. Stats HUD (`-qaShowStats`): format, fps, drops, decode/upload/present ms, audio buffer.
3. Screenshot: read back pass 1 → PNG in `$(xdg-user-dir PICTURES)/HDMI Captain` + `Gdk.Clipboard` texture. Ctrl+Shift+S. No UI in the image (checked).
4. Latency test: the shared probe (flash pattern + timing) ported or reused.
