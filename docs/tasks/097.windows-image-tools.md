## Objective

The free monitoring tools that live in the shader: tasks 036, 039, 040 and 041 brought to Windows.

## Relevant files / modules

- `docs/spec.md` §13 — Windows requirements

## Steps

1. Image adjustments (brightness, contrast, saturation, gamma…) and presets in pass 1, same ranges as Mac.
2. `.cube` LUT import (parser from 087) as a 3D texture; strength slider.
3. Frame guides (safe areas, grid, aspect masks) in pass 2, never in outputs; test-pattern menu.
4. Scopes (histogram, waveform, vectorscope) from a compute shader on a downsampled frame, in a side panel; `-qaAction scopes`.

## Acceptance criteria

- [ ] Adjustments and LUT output match the Mac within tolerance on the same test pattern (WARP test)
- [ ] Guides and scopes never appear in screenshots or recordings
- [x] Scopes cost < 1 ms GPU at 1080p60 on this PC (PIX or timestamp queries)
