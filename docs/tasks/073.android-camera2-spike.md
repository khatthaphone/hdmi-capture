# 073 — Spike A: Camera2 external camera path

**Status:** in-progress
**Phase:** Phase 5: Android
**Depends on:** 069
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Measure whether Camera2 `LENS_FACING_EXTERNAL` is usable on the devices we have, so the ADR can decide if `Camera2Source` ships. Needs hardware: an Android device with USB-C host mode + the UGREEN cards + an HDMI source. If none is available, set `blocked` and ask the user; don't fake results.

## Relevant files / modules

- `docs/spec.md` §12 — Android requirements
- `docs/research/android.md` — research
- `docs/research/android.md` §2a

## Steps

1. Check `FEATURE_CAMERA_EXTERNAL` and list cameras with `LENS_FACING_EXTERNAL` on each device, with the cards plugged in.
2. Where present: open via Camera2 into an ImageReader (`YUV_420_888`) → 071 renderer; record sizes, fps ranges, measured fps and latency.
3. Record 'not exposed' results too (that is the expected outcome on most phones).

## Acceptance criteria

- [ ] Per-device table (model, Android version, exposed? sizes/fps) in the research doc
- [ ] Recommendation for ADR: ship / don't ship `Camera2Source`
