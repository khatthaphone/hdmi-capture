# 075 — UAC audio spike: Oboe full duplex from the card

**Status:** in-progress
**Phase:** Phase 5: Android
**Depends on:** 069
**Complexity:** critical — suggested model: Claude Code → opus/fable · Codex → sol

## Objective

Play the card's HDMI audio with low latency, routed explicitly to the card's USB input, without conflicting with the UVC stream. Needs hardware: an Android device with USB-C host mode + the UGREEN cards + an HDMI source. If none is available, set `blocked` and ask the user; don't fake results.

## Relevant files / modules

- `docs/spec.md` §12 — Android requirements
- `docs/research/android.md` — research
- `Packages/CaptureCore/Sources/CaptureCore/AudioPipeline.swift`, `AudioRingBuffer.swift` — features + ring design to mirror
- `docs/research/android.md` §5

## Steps

1. Oboe 1.11 (prefab) in `core:audio`; find the `TYPE_USB_DEVICE` input matching the card; full duplex low-latency to the current output.
2. Ring buffer with delay 0–500 ms, L/R swap, mono fix; MS2109 48 kHz stereo quirk fallback.
3. Run together with 072's video stream; try both plug orders; measure capture→speaker latency and buffer level over 10 min.

## Acceptance criteria

- [ ] Card audio plays with video running on at least one device
- [ ] Latency + buffer drift numbers logged
- [ ] No interface conflict with the UVC stream (log evidence)
