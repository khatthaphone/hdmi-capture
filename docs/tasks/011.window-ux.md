## Steps

1. Lock `contentAspectRatio` to source aspect; update when format changes.
2. Native full screen; double-click toggles.
3. Float on top (`.floating` level) and show on all Spaces (`.canJoinAllSpaces`) toggles, persisted.
4. Borderless clean mode (hide titlebar/traffic lights, drag anywhere to move).
5. Cursor auto-hide after 2 s idle over the video.
6. Menu commands + shortcuts: ⌘F, ⌘M, ⌘1–⌘4, ⌘T, ⌘,.
