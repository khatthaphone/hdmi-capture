## Objective

Show several capture cards at once in one window (gap #10). The user owns two UGREEN cards already.

## Relevant files / modules

- `Apps/macOS/Sources/` — grid view + per-tile engine/renderer
- `CaptureEngine.swift / MetalRenderer.swift` — one instance per tile
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Grid window: auto layout 1 / 1×2 / 2×2 for connected cards; each tile has its own CaptureEngine + MetalRenderer + label.
2. Only the focused tile plays audio; click a tile to focus; double-click to pop it out to its own window.
3. Warn when dropped frames climb on a tile (likely shared USB 2.0 bandwidth) with a hint to use separate ports.

## Acceptance criteria

- [ ] Both UGREEN cards live simultaneously in a 1×2 grid at their auto formats
- [ ] Audio follows the focused tile only
- [ ] Unplugging one card leaves the other tile running
