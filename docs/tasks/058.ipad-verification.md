End-to-end check of the iPad app on real hardware before App Store work: the iPad equivalent of 014.

## Steps

1. Run the checklist: hot-plug, both UGREEN cards, every scale mode, audio sync, rotation, Split View / Stage Manager, background and resume, screenshot, record, Save Recent, Pro lock/unlock (local StoreKit).
2. Soak: 30 min of a PS5 at 1080p60 with the screen on. Log fps, dropped frames, memory and thermal state (`ProcessInfo.thermalState`) every minute.
3. Write `docs/research/devices/ipad-<model>.md` with the formats each card exposes on iPadOS, compared with macOS.
4. Record the open App Store questions for 045 (universal purchase, iPad screenshots, review notes about the external camera), which are blocked on the Developer account.
