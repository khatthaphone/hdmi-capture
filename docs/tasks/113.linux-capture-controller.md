## Steps

1. `DeviceCatalog`: sysfs scan + libudev monitor (host) / inotify on `/dev` + rescan (Flatpak or no udev), keys from VID:PID + serial/name, USB path tiebreak. The remembered device wins; otherwise the newest.
2. `CaptureController` drives the shared `CaptureState`/`RecoveryMachine`: `ENODEV`/`POLLERR` → recovering; `EBUSY` → paused in use (retry); `EACCES` → permission card; no frames → no signal (`SignalMonitor`).
3. Sleep/resume: logind `PrepareForSleep` over D-Bus with a delay inhibitor. Close cleanly on sleep, recover on wake.
4. Idle inhibit while live (`Gtk.Application.Inhibit` IDLE). rtkit/Realtime-portal priority for the capture and audio threads, with a quiet fallback.
5. Autosuspend check: read `power/control`; if it's `auto`, log it and expose it for the Connection Help screen.
6. Unit tests for the catalog matching and the errno → state mapping. Hardware checks via `wsl-card.ps1 detach/attach` (scripted unplug) and, on real Linux, cable pulls and suspend.

## Acceptance criteria

- [ ] Scripted detach/attach in WSL (or a cable pull on real Linux) recovers to live with no user action, logged
- [ ] A second app streaming the card shows "In use" and we recover when it stops
- [ ] Suspend/resume recovers on real Linux (or is left open in the log with the reason)
- [ ] Never stops capture for focus/minimize/workspace changes (logs show no restart)
