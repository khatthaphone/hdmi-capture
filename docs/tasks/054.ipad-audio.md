# 054 — iPad HDMI audio passthrough

**Status:** in-progress
**Phase:** Phase 3: iPadOS
**Depends on:** 053
**Complexity:** critical — suggested model: Claude Code → opus/fable · Codex → sol

## Objective

Play the card's HDMI audio on the iPad's speakers or headphones with low latency, and never fall back silently to the built-in mic. It is critical because of iOS's single-input audio model, and because a mistake here means you hear the room instead of the game.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/AudioPipeline.swift` — `#if os(macOS)` output-device selection; iOS needs an AVAudioSession path
- `Packages/CaptureCore/Sources/CaptureCore/CaptureEngine.swift:95` — `audioOutput.audioSettings` is macOS-only, so iOS gets the native format and `enqueue` must convert (AVAudioConverter) to the pipeline's 48 kHz stereo float
- `docs/research/ipados.md` — platform facts and sources for this phase

## Steps

1. Configure AVAudioSession: `.playAndRecord`, mode `.default`, options `.defaultToSpeaker, .allowBluetoothA2DP`, and a small `preferredIOBufferDuration` (~5 ms). Set the preferred input to the `.usbAudio` port.
2. Handle route changes (card unplugged, headphones in) and interruptions (a phone call or Siri): restart output, and keep the session configured.
3. Convert native-format capture samples in `AudioPipeline.enqueue` (sample rate, channel count, int vs float). Unit-test the converter with synthetic buffers.
4. Make mute, volume and the level meter work on iPad. Keep the audio delay and channel-fix features from 031.
5. If the active input isn't `.usbAudio`, mute the output and show "Card audio not available".

## Acceptance criteria

- [x] Unit tests for the native-format conversion pass on the iOS simulator
- [ ] On a USB-C iPad with a PS5/console source, game audio plays from the speakers with the picture and no audible drift over 10 minutes (**hardware**)
- [ ] Plugging headphones in moves the audio to them; unplugging the card mutes it rather than switching to the built-in mic (**hardware**)
