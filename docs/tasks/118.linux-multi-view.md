# 118 — Linux Multi-View: window per card + grid

**Status:** in-progress
**Phase:** Phase 10: Linux
**Depends on:** 114
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Several cards at once: one window per card, and a grid window that composes every tile in one GLArea.

## Relevant files / modules

- `docs/spec.md` §14 — Linux requirements
- `docs/research/linux.md` — research (2026-10-23)
- `Apps/Windows` task 098 (`GridWindow`)
- `Apps/Windows/src/HDMICaptain.Core/TileLayout.cs`

## Steps

1. One `CaptureController` per open card. Open Cards opens a window each (`-qaAction openCards`).
2. Grid: one GLArea, tiles from `TileLayout`, per-tile labels as overlays, audio follows the focused tile.
3. With `-testPattern`, the grid shows the four patterns as tiles (`-qaAction grid`).

## Acceptance criteria

- [x] The grid shows four test-pattern tiles in WSLg
- [ ] Two real cards run side by side at full rate on real Linux (or this criterion is left open in the log until the second card is attached)
