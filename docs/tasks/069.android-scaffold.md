## Objective

Create `Apps/Android` as a command-line-buildable Gradle project with the module layout from spec §12.9, so every later Android task has a home and a `make` target.

## Relevant files / modules

- `docs/spec.md` §12 — Android requirements

- `Makefile` — add targets next to `build-ipad`/`run-ipad`
- `CLAUDE.md` — document the commands

## Steps

1. Use JDK 21 from Android Studio's JBR (`/Applications/Android Studio.app/Contents/jbr/Contents/Home`); the system JDK 26 is too new. Generate the Gradle wrapper (9.6.x) and commit it.
2. `gradle/libs.versions.toml` + `build-logic/` convention plugins (compileSdk/targetSdk 36, minSdk 29, JVM 17 bytecode, NDK 28.2.13676358, CMake from the SDK). AGP 9 built-in Kotlin: don't apply `org.jetbrains.kotlin.android`.
3. Modules: `app`, `feature:viewer`, `feature:settings`, `core:model` (pure JVM), `core:capture`, `core:render`, `core:audio`, `core:billing` — empty but building; one NDK module (`core:render`) with a trivial JNI call to prove the CMake path.
4. Application id `com.example.hdmicaptain` (placeholder, same as Apple); app name, adaptive launcher icon from `Design/AppIcon` (concept A gold helm).
5. Makefile: `android-build` (assembleDebug), `android-test` (JVM + Robolectric), `android-run` (installDebug + `adb shell am start`, `ANDROID_ARGS` → intent extras). `.gitignore` for build outputs and `local.properties`.
6. Verify 16 KB alignment of the APK (`zipalign -c -P 16 -v 4`).

## Acceptance criteria
