## Objective

Add an `HDMICaptain-iPad` application target (iPad only, iPadOS 17+) that builds and launches on the simulator with a test pattern, so device work has a home.

## Relevant files / modules

- `project.yml` — new target, `platform: iOS`, `TARGETED_DEVICE_FAMILY: 2`
- `Apps/iPadOS/Sources/` — new SwiftUI `App`
- `Config/Signing.xcconfig` / gitignored `Config/Local.xcconfig` — personal-team signing (`DEVELOPMENT_TEAM`)
- `Makefile` — `make build-ipad`, `make run-ipad-sim`
- `docs/research/ipados.md` — platform facts and sources for this phase

## Steps

1. Add the target to `project.yml`. Its sources are `Apps/iPadOS/Sources` + `Apps/Shared`. It depends on CaptureCore and **not HaishinKit** (streaming stays hidden, 046). Deployment target iPadOS 17.0, device family 2.
2. Info.plist: `NSCameraUseExternalDeviceType=true`, `NSCameraUsageDescription`, `NSMicrophoneUsageDescription`, `NSPhotoLibraryAddUsageDescription`, `UIFileSharingEnabled`, `LSSupportsOpeningDocumentsInPlace`, `UIRequiresFullScreen=false` (needed for Stage Manager / multitasking camera), and all four orientations.
3. A minimal `App` + root view showing CaptureCore's `TestPattern` through a placeholder view (the real Metal view is 053).
4. Support DEBUG launch arguments the same way as on macOS (`-testPattern`, `-qaAction`), via `xcrun simctl launch … -testPattern smpteBars`.
5. Add make targets and document them in `CLAUDE.md`, including how to sign for a personal team via `Config/Local.xcconfig`.
6. Add the app icon set if 048 has produced one; otherwise a placeholder.
