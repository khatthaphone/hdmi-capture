**Status:** done

**Depends on:** 061
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

VoiceOver, Dynamic Type, contrast and Reduce Motion work across the bar, overlays and settings on both platforms.

## Relevant files / modules

- `Apps/Shared/ControlBar.swift` — icon-only buttons need labels; `.help` is not a VoiceOver label on iOS
- `Apps/Shared/PauseIllustration.swift` — the arrow animation should respect Reduce Motion
- design:accessibility-review skill

## Steps

1. Give every icon-only control an `accessibilityLabel`, and the Record and mute buttons a value or state.
2. Respect Reduce Motion (phaseAnimator arrow, bar slide); check contrast of text on the see-through bar over bright video.
3. Check the iPad Settings sheet and the overlays at the largest Dynamic Type size, and the Mac with VoiceOver.

## Acceptance criteria

- [x] VoiceOver reads every bar control meaningfully on Mac and iPad (checked by hand, notes in the log)
- [x] Reduce Motion disables the arrow animation and the bar slide
- [x] Accessibility Inspector audit on the Mac shows no missing labels for our controls
