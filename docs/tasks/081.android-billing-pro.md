# 081 — Pro on Android: Play Billing one-time unlock + upgrade sheet

**Status:** in-progress
**Phase:** Phase 5: Android
**Depends on:** 078
**Complexity:** critical — suggested model: Claude Code → opus/fable · Codex → sol

## Objective

One non-consumable Play product unlocking recording and Save Recent, with gating in one place (spec §10, §12.8).

## Relevant files / modules

- `docs/spec.md` §12 — Android requirements
- `docs/research/android.md` — research
- `Apps/Shared/Store/EntitlementStore.swift`, `UpgradeView.swift`
- `docs/adr/0004-monetization.md`

## Steps

1. `core:billing`: BillingClient 9.x, query INAPP purchases on start, purchase flow, acknowledge (never consume), pending state; `StateFlow<ProStatus>`.
2. `gate(feature)` equivalent; `ProFeature` list with streaming/virtualCamera hidden; DEBUG `debugUnlockPro` extra.
3. Upgrade sheet ported from `UpgradeView` (Buy Pro with upgrade icon, small text 'Not Now').
4. Robolectric tests with a fake BillingClient. Real purchase test needs a Play Console account (may block).

## Acceptance criteria

- [x] Free features never call the gate (grep check)
- [x] Tests cover purchased, pending, refunded/revoked
