# 009 — AudioMonitor: HDMI audio passthrough, volume, mute

**Status:** in-progress
**Phase:** Phase 1: macOS MVP viewer
**Depends on:** 006
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Play the dongle's audio through the Mac's output with volume control and 'Silent Mode' mute (spec §5.5).

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/AudioMonitor.swift` — new
- `CaptureEngine.swift` — add audio input
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. Add paired audio device as a second `AVCaptureDeviceInput` to the same session (keeps A/V clock aligned).
2. Use `AVCaptureAudioPreviewOutput` (macOS) with `volume`; mute = volume 0 without tearing down.
3. Allow choosing output device (`outputDeviceUniqueID`) — default system output.
4. Handle audio device missing gracefully (video continues).

## Acceptance criteria

- [ ] Audio audible from dongle; mute/unmute instant (< 100 ms) with no session restart
- [ ] Unplugging only audio does not stop video
- [ ] Subjective A/V sync: no visible lip-sync offset on a talking-head source (note measured offset in log)
