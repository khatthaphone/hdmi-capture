## Objective

Replace AVCaptureAudioPreviewOutput with AVCaptureAudioDataOutput → AVAudioEngine so we can offer the #1 missing feature in the market (competitors.md gap #2): adjustable audio delay, L/R swap, mono→stereo fix, output-device choice, level meters. Also the sample source for recording (016) and the mixer (024). Critical because it runs on the real-time audio thread.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/CaptureEngine.swift` — replace audioPreview with AVCaptureAudioDataOutput on its own queue
- `Packages/CaptureCore/Sources/CaptureCore/AudioPipeline.swift` — new: ring buffer → AVAudioSourceNode → engine
- `Packages/CaptureCore/Sources/CaptureCore/Presets.swift` — add audioDelayMs, swapChannels, channelMode, outputDeviceID (decodeIfPresent)

## Steps

1. Add AVCaptureAudioDataOutput; deliver CMSampleBuffers to AudioPipeline (convert with AVAudioConverter to engine format, float32 stereo 48 kHz).
2. Lock-free SPSC ring buffer (unit-tested) between capture queue and AVAudioSourceNode render block; no allocation/locks on the render thread.
3. Delay 0–500 ms (10 ms steps) = target buffer fill; drift controller keeps fill within ±10 ms of target by dropping/duplicating ≤1 sample per 1000 (tested pure function).
4. Channel matrix: normal / swap L-R / left→both / right→both / mono mix; auto-detect sticks that report mono and up-mix.
5. Output device selection via the engine output unit's kAudioOutputUnitProperty_CurrentDevice; follow default device if none chosen.
6. Peak/RMS meter via tap at ~20 Hz published to UI.
7. Remove AVCaptureAudioPreviewOutput path; keep volume/mute behaviour from 009.

## Acceptance criteria

- [ ] Audio delay audibly changes in 10 ms steps from 0 to 500 ms without clicks or restarts
- [ ] Swap L/R and mono→both verified with a left-only test tone
- [ ] Choosing AirPods / built-in speakers as output works while live
- [ ] 30-minute run: buffer fill stays within ±20 ms of target (log every 10 s)
- [ ] Unit tests for ring buffer, channel matrix and drift controller pass
- [ ] Instruments Time Profiler: no allocations on the audio render thread
