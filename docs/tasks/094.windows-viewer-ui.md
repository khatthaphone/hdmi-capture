# 094 — Windows viewer window: status screens, control bar, window behaviour, shortcuts

**Status:** in-progress

## Objective

The WinUI main window equivalent of `ContentView` + `ControlBar` + `WindowConfigurator`: what the user sees and how the window behaves.

## Relevant files / modules

- `docs/spec.md` §13 — Windows requirements
- `docs/research/windows.md` — research (2026-10-22)
- `Apps/Shared/ContentView.swift`, `ControlBar.swift`, `StatusScreens.swift`, `HelpSheet.swift`, `MenuItems.swift`
- `Apps/macOS/Sources/WindowConfigurator.swift`, `HDMICaptainApp.swift` (menu commands)
- `docs/copy.md` — all copy
- `Apps/Android/feature/viewer/` — another port of the same UI

## Steps

1. `AppModel`/`ViewerModel` in C# (`CommunityToolkit.Mvvm` source generators, AOT-safe) bound to the controller's state.
2. Status screens for every state (permission/privacy, scanning, connecting, no signal, HDCP, in use, recovering), with the connect illustration and Connection Help, using the copy from `docs/copy.md` in `.resw` with Windows wording.
3. Hover control bar near the bottom edge (input, volume, screenshot, Save Recent, Record, view options) that fades after 3 s; `-qaPinControls`. It's XAML above the video and never in outputs.
4. Window: aspect-locked resize (`WM_SIZING` subclass via CsWin32), borderless clean mode, always on top (`OverlappedPresenter`), borderless full screen (F11/Alt+Enter, double-click), cursor auto-hide, Mica + dark title bar, per-monitor DPI v2, remembered size and position.
5. Shortcuts per spec §13.7 (`KeyboardAccelerator`); right-click context menu with the Mac menu items; first-run welcome card as on Mac (062).
6. UI Automation names on every control, full keyboard navigation, high-contrast check.

## Acceptance criteria

- [ ] Every `CaptureState` has a screen that matches `docs/copy.md` (screenshots in this log, via `-testPattern` and fake states)
- [ ] Aspect lock, clean mode, always on top, full screen and shortcuts work; the control bar never shows up in a screenshot
- [x] Narrator reads every control in the main window
