## Objective

When the iPad is connected to an external display, show the clean picture there (no bar or HUD), with the iPad screen acting as the controller. Useful for streaming setups and big-screen viewing.

## Relevant files / modules

- `docs/research/ipados.md` — platform facts and sources for this phase
- `Packages/CaptureCore/Sources/CaptureCore/MetalRenderer.swift` — a second render target or a second renderer on the same sink

## Steps

1. Use a second `WindowGroup`/scene for the external display. Non-interactive external scenes need a scene accessory from iOS 27, so check against the installed SDK.
2. Render the same frames to the external scene's Metal layer, matching the display's refresh rate where possible.
3. Choose between "mirror the iPad" and "clean feed on the external display" in Settings; default to the clean feed.
4. Handle the display disconnecting without disturbing capture.

## Acceptance criteria

- [ ] With a USB-C/HDMI display attached, the external screen shows the full-screen clean picture while the iPad shows the controls (**hardware**)
- [ ] Unplugging the display mid-session doesn't stop capture or crash
