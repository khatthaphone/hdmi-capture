# 018 — Multiple devices / windows

**Status:** in-progress
**Phase:** Phase 2: macOS polish
**Depends on:** 012
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Allow one window per connected dongle (e.g. two consoles side by side).

## Relevant files / modules

- `Apps/macOS/` — WindowGroup per device
- `CaptureEngine.swift` — multiple instances
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. One `CaptureEngine` per window bound to a device `uniqueID`; File → New Window picks a device.
2. Prevent two windows opening the same device (or share one engine).

## Acceptance criteria

- [ ] Two dongles run simultaneously at their native formats
- [ ] Closing one window does not affect the other
