# 046 — Direct streaming of the HDMI input (Pro)

**Status:** in-progress
**Phase:** Phase 8: Pro & monetization
**Depends on:** 016, 042
**Complexity:** critical — suggested model: Claude Code → opus/fable · Codex → sol

## Objective

Go live with just the capture card (no compositor yet): RTMP/SRT to Twitch/YouTube/custom. Critical because it handles stream keys.

## Relevant files / modules

- `project.yml` — add HaishinKit (BSD) package
- `Packages/CaptureCore/Sources/CaptureCore/Streamer.swift` — new, reuses encoder settings from 016
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Output profiles: service presets (Twitch, YouTube, custom RTMP/SRT), resolution, fps, bitrate, keyframe 2 s.
2. Stream key stored in Keychain only; never logged.
3. Live indicator, bitrate/health, auto-reconnect on network drop.
4. Gate behind EntitlementStore (.streaming).

## Acceptance criteria

- [ ] 30-min test stream to a private YouTube/Twitch target with no A/V drift
- [x] Stream key absent from logs, UserDefaults and crash reports
- [ ] 10-second network cut → automatic reconnect
- [ ] Locked when Pro not purchased
