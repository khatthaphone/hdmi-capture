# 082 — Android recording & Save Recent (Pro)

**Status:** in-progress
**Phase:** Phase 5: Android
**Depends on:** 081, 075
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

MediaCodec recording of the clean feed + card audio, and the rolling Save Recent buffer.

## Relevant files / modules

- `docs/spec.md` §12 — Android requirements
- `docs/research/android.md` — research
- `Packages/CaptureCore/Sources/CaptureCore/Recorder.swift`, `RollingRecorder.swift`
- `docs/research/android.md` §6

## Steps

1. Encoder input surface on a shared EGL context fed the decoded frames; HEVC with H.264 fallback; AAC from the audio ring; MP4 to MediaStore `Movies/HDMI Captain`.
2. Save Recent: encoded GOP ring (15/30/60 s) muxed on save.
3. Stop cleanly when capture stops (app hidden, unplug).

## Acceptance criteria

- [ ] Recordings play with A/V in sync and contain no UI
- [ ] Recording across unplug stops cleanly with a valid file
