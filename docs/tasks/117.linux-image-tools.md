## Objective

Bring the image tools to Linux. Most of the logic is in the shared renderer and Core (CubeLUT, ScopeData, GuideSettings), so this is wiring and UI.

## Relevant files / modules

- `docs/spec.md` §14 — Linux requirements
- `docs/research/linux.md` — research (2026-10-23)
- `Apps/Windows` task 097
- `Apps/Windows/src/HDMICaptain.Core/CubeLUT.cs`, `ScopeData.cs`, `GuideSettings.cs`
- `native/render-gles/` LUT and guide passes

## Steps

1. Adjustments (brightness/contrast/saturation/gamma) and `.cube` LUT import (`Gtk.FileDialog`) applied in pass 1.
2. Guides (safe areas, grid, centre) drawn as overlays, never in outputs.
3. Scopes (histogram, waveform, vectorscope) computed from pass-1 readback at low rate, in a side panel.
4. `-qaAction scopes` for screenshots.

## Acceptance criteria

- [x] LUT and adjustments change pass 1 (screenshot shows them); guides don't appear in screenshots
- [x] Scopes update live without dropping capture frames
