## Objective

Pure function choosing the best `AVCaptureDevice.Format` + frame duration for a device given user preferences (spec §5.2). Kept pure so it's trivially testable and reusable on iPadOS.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/FormatSelector.swift` — new
- `docs/research/devices/` — real format lists to use as fixtures
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. Define a value type `FormatDescriptor` (width, height, fourCC, fps ranges) mapped from `AVCaptureDevice.Format`.
2. Implement `select(from: [FormatDescriptor], preference: FormatPreference) -> Choice?` where preference is auto or pinned (resolution, fps).
3. Auto policy: highest pixel count at ≥ 50 fps, else highest fps at max resolution; prefer `420v`/`yuvs` over MJPEG when equal.
4. Fixtures from 002 output (or hand-written if 002 not done) as JSON in Tests/Resources.

## Acceptance criteria

- [ ] ≥ 8 test cases incl. 1080p60 vs 4K30 dongle, MJPEG-only dongle, pinned unavailable fps falls back sensibly, empty list returns nil
- [ ] No AVFoundation import in the pure selection logic file (mapping lives in an extension)
