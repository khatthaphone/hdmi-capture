## Objective

User-facing side of the unlock: upgrade sheet, PRO badges, restore, and graceful locked states.

## Relevant files / modules

- `Apps/macOS/Sources/Store/` — UpgradeView using StoreKit SwiftUI views
- `HDMICaptainApp.swift / SettingsView.swift` — badges, Pro settings tab
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Upgrade sheet listing Pro features with price from StoreKit; Restore Purchases button.
2. Menu items for Pro features show a PRO badge; choosing one while locked opens the sheet.
3. Settings → Pro tab with status, restore, and 'thank you' state.
4. Never interrupt live viewing with nags; no time limits on the free viewer.

## Acceptance criteria

- [ ] Locked Pro actions open the sheet and never crash or half-start
- [ ] After purchase (StoreKit testing) every Pro item unlocks without relaunch
- [ ] Free viewer flows show no upgrade prompts unless a Pro feature is chosen
