**Status:** in-progress
**Phase:** Phase 5: Android
**Depends on:** 078
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Port the free viewer features (spec §10 free column) that exist on iPad.

## Relevant files / modules

- `docs/spec.md` §12 — Android requirements
- `docs/research/android.md` — research
- `Packages/CaptureCore/Sources/CaptureCore/SignalAnalyzer.swift`, `CubeLUT.swift`
- `Apps/Shared/ScopesPanel.swift`

## Steps

1. No-signal/HDCP detection from a native 160×90 sample grid via `SignalAnalyzer` (070); hold last frame.
2. Diagnostics HUD (in/out fps, drops, latency, format, link speed); guides; test patterns menu; LUT 3D texture; image adjustments in the shader.
3. Screenshot → PNG via MediaStore; copy frame to clipboard. Scopes optional (log if deferred).

## Acceptance criteria

- [ ] Unplugging HDMI from the source shows the No HDMI signal screen
- [ ] Screenshot saved with no UI
