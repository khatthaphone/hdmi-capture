# 007 — Always-on: no disconnect on focus/Space loss, auto-recovery

**Status:** in-progress
**Phase:** Phase 1: macOS MVP viewer
**Depends on:** 006, 001

## Objective

The reason this project exists (spec §5.3, G2/G3): guarantee capture survives focus loss, Space switches, minimize, occlusion, screen lock, and recovers from runtime errors and replug.

## Relevant files / modules

- `CaptureEngine.swift` — add recovery
- `docs/research/dongled-disconnect.log` — which events Dongled suffers from (task 001)
- `docs/spec.md` — authoritative product/technical spec

## Steps

1. Hold `ProcessInfo.beginActivity([.userInitiated, .latencyCritical, .idleDisplaySleepDisabled])` while live; release on stop.
2. Observe `runtimeErrorNotification`, `wasInterruptedNotification`, `interruptionEndedNotification`; restart with exponential backoff 0.25 s → 4 s cap; log each event via `os.Logger` (subsystem `hdmicaptain`, category `capture`).
3. On device reconnect with remembered `uniqueID`, rebuild session automatically.
4. Ensure nothing stops the session on `NSApplication.didResignActive`, window occlusion, or `NSWorkspace` sleep/wake (re-validate session on wake).
5. Write `docs/research/resilience-test.md` with the manual test matrix and results.

## Acceptance criteria

- [ ] Manual matrix passes: other app focused, Space switch, minimize, other app full-screen, screen lock 5 min, display sleep/wake, system sleep/wake, unplug/replug — capture live on return each time
- [ ] `log show --predicate 'subsystem == "hdmicaptain"'` shows no unrecovered interruption during the matrix
- [ ] Replug reconnects in ≤ 2 s without user action
