# 037 — Console profiles

**Status:** done
**Phase:** Phase 7: Viewer features (free)
**Depends on:** 012, 031, 036
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Per-console UX (gap #5): named profiles with an icon that bundle format, scaling, filter, image and audio settings, auto-applied per card.

## Relevant files / modules

- `Presets.swift` — Profile model; DevicePreset references active profile
- `SettingsView.swift / HDMICaptainApp.swift` — profile switcher in settings, Video menu and menu bar
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Profile = id, name, SF Symbol/emoji, settings snapshot (format, scale, filter, colorRange, image adjustments, audio delay/channel).
2. Built-ins: Retro (integer + sharp), Modern Console (fit, 60 fps priority), Camera (fill off, cinema look), Desktop (1080p, sharp text).
3. Assign a default profile per device; quick switch with ⌥⌘1…9.
4. Import/export profiles as JSON.

## Acceptance criteria

- [x] Switching profile applies all settings within one frame (format change may restart session)
- [x] Device reconnect restores its assigned profile
- [x] Export → delete → import round-trips
