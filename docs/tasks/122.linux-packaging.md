## Objective

Produce installable builds: a Flatpak (the Flathub-ready manifest) as the main channel, a .deb/.rpm that also installs the udev rule, and a self-contained tarball for CI and fallback.

- Flathub submission requirements: https://docs.flathub.org/docs/for-app-authors/requirements

## Steps

1. Flatpak manifest `com.example.HDMICaptain` (app id to be finalised with the real domain): GNOME runtime (version matching Gir.Core's needs), `org.freedesktop.Sdk.Extension.dotnet10`, offline NuGet sources (`flatpak-dotnet-generator`), libturbojpeg and the renderer built in the manifest. finish-args: `--device=all`, `--socket=wayland`, `--socket=fallback-x11`, `--socket=pulseaudio`, `--share=ipc`, `--filesystem=xdg-pictures/HDMI Captain:create`, `--filesystem=xdg-videos/HDMI Captain:create`, `--talk-name=org.freedesktop.login1` (sleep inhibitor) if needed. Justify `--device=all` in the submission notes (raw V4L2).
2. `.desktop`, AppStream metainfo (screenshots, releases, OARS) passing `appstreamcli validate` / `flatpak-builder-lint`; icons at the standard sizes.
3. `.deb` (dpkg-deb or nfpm) and `.rpm` with the self-contained publish under `/opt/hdmi-captain`, a launcher, the udev rule `60-hdmicaptain.rules`, and postinst `udevadm trigger`.
4. `.tar.gz` of the self-contained publish for CI.
5. `make linux-package` builds all of them (Flatpak where `flatpak-builder` is present). Install-test the .deb in WSL and the Flatpak on real Linux.

## Acceptance criteria

- [ ] `make linux-package` produces a Flatpak bundle, a .deb, an .rpm and a tarball
- [ ] The .deb installs in WSL Ubuntu, launches from the menu entry and shows test patterns; the udev rule is in place
- [ ] `flatpak-builder-lint` passes (or the remaining exceptions are logged with reasons)
