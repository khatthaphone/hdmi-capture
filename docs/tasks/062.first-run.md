## Objective

Someone opening the app with no card should understand in 5 seconds what to plug in and where, and why it asks for camera and microphone access, before the system prompt appears.

## Relevant files / modules

- `Apps/Shared/AppModel.swift` — `requestPermissions()` (currently asks immediately on launch)
- `Apps/Shared/ContentView.swift` — the scanning state
- `docs/research/ipados.md` — the iPad USB-C-only note

## Steps

1. Show a pre-permission explainer ("HDMI capture cards appear as cameras…") with a Continue button that triggers the system prompt. Only on the first run.
2. Improve the "connect a card" state: an illustration, supported-hardware hint (USB-C iPad; UVC cards), and a link to a short help page or troubleshooting sheet (HDCP, power, cable).
3. On the iPad, explain the background and Split View pause once (non-blocking tip).

## Acceptance criteria

- [ ] Fresh install (reset with `-qaResetFirstRun YES`): the explainer appears before the system camera prompt on both platforms
- [ ] The troubleshooting sheet covers no signal, HDCP (PS5 setting path), no sound (iPad route) and the card not detected
