# 038 — Instant replay buffer (Pro)

**Status:** done
**Phase:** Phase 8: Pro & monetization
**Depends on:** 016
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Keep the last N seconds encoded in memory and save them with a hotkey — a CaptureLink-only feature today.

## Relevant files / modules

- `Packages/CaptureCore/Sources/CaptureCore/ReplayBuffer.swift` — new, ring of encoded GOPs
- `Recorder.swift` — shared encoder setup from 016
- `docs/spec.md` — authoritative product/technical spec (§10 business model, §11 feature expansion)

## Steps

1. Encode continuously with VideoToolbox (HEVC) + AAC while enabled; keep a ring of whole GOPs covering 15–120 s (setting) with a memory cap.
2. ⇧⌘R saves the ring to an MP4 (starting at a keyframe) without stopping capture.
3. Gate behind EntitlementStore (.replayBuffer).

## Acceptance criteria

- [x] Saved clip duration matches setting ±1 GOP and plays with A/V sync
- [x] Memory stays under the cap during a 30-min session
- [x] Locked when Pro not purchased (shows upgrade sheet)
