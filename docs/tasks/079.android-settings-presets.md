# 079 — Android settings, device/format pickers & per-device presets

**Status:** in-progress
**Phase:** Phase 5: Android
**Depends on:** 078
**Complexity:** complex — suggested model: Claude Code → sonnet · Codex → terra

## Objective

Settings sheet/pane with the same options as iPad Settings, persisted per device.

## Relevant files / modules

- `docs/spec.md` §12 — Android requirements
- `docs/research/android.md` — research
- `Apps/iPadOS/Sources/SettingsSheet.swift`
- `Apps/Shared/Model/ViewerPrefs.swift`, `Packages/CaptureCore/Sources/CaptureCore/Presets.swift`, `Profiles.swift`

## Steps

1. DataStore-backed prefs with the same keys; per-device presets by stable key; console profiles.
2. Video input, format (shows USB 2.0 limit), scale/filter/colour, image adjustments, LUT import (SAF), audio (volume, delay, swap, mono), diagnostics.
3. List-detail on large screens; full-screen on phones.

## Acceptance criteria

- [ ] Settings survive restart and re-plug of the same card
- [ ] Robolectric tests for prefs and presets
