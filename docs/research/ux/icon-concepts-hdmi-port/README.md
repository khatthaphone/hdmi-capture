## Shared prompt direction

Make a recognizable HDMI female port the primary silhouette. Use custom simplified geometry rather than copying the official HDMI Port Design Logo. No text, letters, nautical imagery, detailed connector pins, blue, or cyan. Each concept uses a deliberately different palette and level of dimensionality.

Before shipping a selected direction, redraw it as controlled vector geometry, review HDMI trademark guidance, create separate iOS/macOS masters, and validate at 16, 32, 64, 128, and 1024 pixels.
