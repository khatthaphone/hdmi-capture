## Directions

- **A — Port Monitor:** the HDMI socket becomes the monitor base. The most compact merged glyph and strongest small-size candidate.
- **B — Pixel Pipeline:** a visible HDMI port sends a grid of pixels into a monitor image. Extremely literal and useful as a composition study, but currently too detailed for a final icon.
- **C — Pixel Screen Port:** a large pixel display contains the HDMI port as bold negative space. Simple, colorful, and distinctive.
- **D — Pixel Wall:** an HDMI port emits chunky pixel cubes that resolve into a screen image. The strongest dimensional concept.

Combine a recognizable HDMI female socket with a display/monitor and large pixels. Use custom simplified geometry rather than copying the official HDMI Port Design Logo. No text, letters, nautical imagery, tiny pins, blue, or cyan. Keep the relationship literal and understandable rather than adding an abstract metaphor.

Recommended next refinement targets: A for maximum legibility, C for a flat graphic identity, or D for a more dimensional Apple-style icon.
