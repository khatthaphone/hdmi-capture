# HDMI Capture — simple, elegant icon pass

Generated with the built-in image-generation tool on 2026-10-21. These are exploration assets only; the shipping app icon was not changed.

## Directions

- **A — Port Frame:** A continuous monitor outline flows into a simplified HDMI port, with one orange capture pixel. The clearest merged symbol.
- **B — Quiet Port:** A centered HDMI socket sits inside a calm display tile, balanced by three small terracotta pixels. The strongest overall direction for an app icon.
- **C — Pixel Window:** A display outline combines a 2×2 pixel cluster with an HDMI-shaped lower notch. More playful and colorful while remaining flat.
- **D — Monitor Cutout:** A burgundy monitor silhouette with a minimal lower port treatment. Elegant in isolation, but the HDMI cue is too weak and should not advance unchanged.

## Shared art direction

Flat geometric vector-style icon; HDMI port plus display/pixel imagery; generous negative space; crisp silhouette; no gradients, glow, shadows, bevels, 3D rendering, text, letters, cable, plug pins, nautical imagery, or official HDMI logo. Avoid blue and cyan. Use custom port geometry rather than the protected HDMI logo artwork.
